# Power Lab VR

## 🇪🇸 Español

### 🎮 Descripción
Power Lab VR es un juego serio cooperativo en Realidad Virtual desarrollado como trabajo de investigación. Su objetivo es analizar si es posible desarrollar habilidades blandas en estudiantes de ingeniería mediante experiencias colaborativas en VR.

El juego sitúa a los jugadores en un laboratorio de energía donde deben coordinarse para resolver tareas, promoviendo comunicación, trabajo en equipo y toma de decisiones conjuntas.

Este proyecto forma parte de una investigación académica y no está destinado a distribución pública.

### 🛠️ Tecnologías
- Unity
- XR Interaction Toolkit
- Realidad Virtual (VR)
- Multijugador cooperativo

### ⚙️ Características Técnicas
- Interacciones VR basadas en físicas
- Sistema multijugador cooperativo
- Mecánicas diseñadas para fomentar colaboración
- Arquitectura orientada a experimentación y análisis de comportamiento

### 🎯 Objetivo del Proyecto
Evaluar:
- La viabilidad del uso de juegos serios en VR
- El nivel de desarrollo de habilidades blandas mediante interacción cooperativa

### 📌 Estado
✔ Proyecto completado  
📄 Uso exclusivo para fines de investigación académica

## 🇬🇧 English

### 🎮 Description
Power Lab VR is a cooperative serious game in Virtual Reality developed as a research project. Its goal is to evaluate whether soft skills in engineering students can be developed through collaborative VR experiences.

Players are placed inside an energy laboratory where they must coordinate to solve tasks, encouraging communication, teamwork, and joint decision-making.

This project is part of an academic research study and is not intended for public distribution.

### 🛠️ Technologies
- Unity
- XR Interaction Toolkit
- Virtual Reality (VR)
- Cooperative Multiplayer

### ⚙️ Technical Features
- Physics-based VR interactions
- Cooperative multiplayer system
- Gameplay mechanics designed to promote teamwork
- Architecture focused on experimentation and player behavior analysis

### 🎯 Project Goal
To evaluate:
- The feasibility of using serious VR games
- The level of soft skill development through cooperative interaction

### 📌 Status
✔ Completed  
📄 Research-only project
